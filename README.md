# Bottle-Opener-for-Disabled

People with upper‑limb functional limitations often face difficulties opening bottles. Place this assistive opener on the edge of a table. Secure the bottle by pushing the shaft forward using body movement. After the bottle is firmly clamped, you can remove the bottle cap with your functional hand or via the built‑in clamp.
